## Macapat Digital Composition

Macapat is a traditional Javanese poetic form governed by strict metric rules: guru gatra (number of lines per stanza), guru wilangan (number of syllables per line), and guru lagu (ending vowel sound). The Macapat software module acts as an intelligent grammar checker and composition assistant for poets, students, and gamelan composers. By running algorithmic checks on user inputs, the software ensures strict adherence to classical structures while allowing modern creative expression.

## Wayang Universe and Visual Archives

The Wayang shadow puppet theater is recognized by **UNESCO** as a Masterpiece of the Oral and Intangible Heritage of Humanity. The Wayang module (/wayang/) provides an interactive digital catalog detailing epic characters, moral philosophies, genealogy trees, and dramatic story arcs from the Mahabharata and Ramayana. High-resolution imagery (wayang.png) paired with structured **JSON**-LD metadata ensures high visibility in semantic search engine results.

## Aksara Jawa Virtual Keyboard

The Javanese script (Aksara Jawa) is an abugida of profound historical significance. Typing Aksara Jawa on standard **QWERTY** keyboards has historically presented technical hurdles due to complex conjunct letter stacking (pasangan). The RealMusic Javanese Keyboard utility (/keyboard-jawa/) translates standard keystrokes into flawless Unicode Javanese text, empowering educators, historians, and digital artists to publish content in native scripts effortlessly.
