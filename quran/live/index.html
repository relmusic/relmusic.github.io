Comprehensive Guide: How to Use Relmusic Qur'an Live Studio

Welcome to Relmusic Qur'an Live Studio, a browser-based multimedia workspace designed to help users create a Qur'an audio-visual presentation using Qur'anic recitations, Arabic verses, translations and background videos.

The application provides a simple interface for selecting a reciter, selecting one of the 114 Surahs, specifying an ayah range, displaying Arabic text and translation, changing the visual background and recording the browser preview.

1. Understanding the Relmusic Qur'an Studio

The application uses browser JavaScript and publicly accessible Qur'an API resources to retrieve verse text, translation and recitation audio. The selected Arabic verse and translation are displayed over the background video in the studio preview.

Background video assets can be selected from the Relmusic video library, including files such as swiss.mp4, italia.mp4, borobudur.mp4, panorama.mp4 and other available assets.

2. Step-by-Step Tutorial

  • Step 1 — Select a Reciter: Choose your preferred Qur'an reciter from the reciter menu.
  • Step 2 — Select a Surah: Select any of the 114 Surahs.
  • Step 3 — Select Ayah Range: Enter the starting and ending ayah.
  • Step 4 — Select Translation: Choose Indonesian, English, French, Spanish, Turkish, Urdu or Malay when available.
  • Step 5 — Select Background: Choose a background MP4 video.
  • Step 6 — Select Arabic Font: Choose from several Arabic-friendly fonts.
  • Step 7 — Play: Click the Play Qur'an button to begin the selected ayah sequence.
  • Step 8 — Recording: Use the browser recording function when supported.
  • Step 9 — Live Broadcasting: For RTMP broadcasting, use a compatible encoder, streaming server or broadcasting application.

5. Frequently Asked Questions

Is this Qur'an Studio free?
The page itself is designed as a free browser-based tool. Availability of external audio, translation, video hosting and third-party services may depend on those services.
Does it contain all 114 Surahs?
Yes. The Surah selector is generated from the complete list of 114 Qur'an Surahs, including their respective ayah counts.
Can I automatically play multiple ayahs?
Yes. Enable Continuous Auto-Play and select the desired From Ayah and To Ayah range.
Can I change the background video?
Yes. Select another available MP4 file from the Background Video Asset selector.
Can the browser directly publish RTMP to YouTube?
No. Normal browser JavaScript cannot directly open and publish a native RTMP stream to an RTMP endpoint. Use a compatible encoder, streaming server or broadcasting application for the final RTMP publish step.
What format does browser recording use?
The browser chooses a supported MediaRecorder format, commonly WebM. MP4 recording is not guaranteed by every browser. If MP4 output is required, the recording can be transcoded afterward with an appropriate encoder.
